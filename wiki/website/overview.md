# 官网能做什么

官网在 [www.endlesspixel.cn](https://www.endlesspixel.cn)。Wiki 主要讲游戏里怎么玩，官网更像是服务站，下载、查状态、看直播、答题这些事都在那边。

![官网首页](/screenshots/home.png)

页面顶部那一排导航是按用途分的，找东西的时候照着分类点就行。

## 首页

进官网第一眼看到的页面。中间那个大按钮写着服务器地址 `mc.endlesspixel.cn`，直接复制就能加服。下面几个快捷入口分别通向状态页、实况、整合包和玩家截图。

首页底部还有一行硬件信息，CPU 型号和内存都是实时拉的。有人拿这个判断服务器会不会卡，倒也不是没道理。

## 下载

整合包和启动器都在 `/downloads`。点进去是四张卡片，每张对应一个下载项。具体怎么选见[下载区那篇](./downloads.md)。

## 站点

状态页和实况页归在这一类。状态页能看各项服务是不是活着，还有近 30 天的可用率。实况页放服务器录像和精彩回放。

![服务状态监控](/screenshots/status.png)

状态页上那个刷新按钮可以手动触发一次重新探测。页面默认每 5 分钟自动更新，时间线格子鼠标悬停能看到当天每次检测的结果。时间用的是 UTC，跟北京时间差 8 小时，看的时候留意一下。

## 玩家

图册、考试、排行、皮肤预览都在这里。

![服务器考试](/screenshots/quiz.png)

考试那个页面挺有意思，题库涵盖接入方式、版本、玩法、整合包这些。成绩只存在浏览器本地，不上传。想摸摸自己对这个服了解多少可以去试试。

![模型排行](/screenshots/rankings.png)

排行页是 AI 模型用量榜，跟游戏本身关系不大，是官网 chatbot 的数据。

## 关于

团队介绍、仓库信息、服务支持渠道。仓库信息页会显示官网仓库的 Star 数、贡献者这些，用的是 GitHub API 实时拉的。

## 登录和个人中心

右上角登录之后进 `/profile`，能看自己的游戏数据，背包、末影箱、统计、成就都有。物品图标走的是第三方渲染服务，方块物品也能正常显示。成就名字有中文翻译，来自数据包自带的语言包，页面底部写了署名。

个人中心需要 Minecraft 账号密码登录，GitHub 账号登进去看不到游戏数据，这点官网上有提示。

## 条款类页面

`/terms` 和 `/privacy` 分别是用户协议和隐私政策。涉及账号和数据处理的规则以这两页为准。

## 几个容易找不到的入口

`/ai_link?url=<链接>` 是 AI 客服回复里附的外链跳转页，会检查域名白名单。直接访问没参数会报错，正常用不着手动输。

`/systemstatus/data` 是接口不是页面，返回宿主机的硬件监控数据。对外展示的地址是 `https://sys.epmc.qzz.io`。
