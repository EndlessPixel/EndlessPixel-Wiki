# 官方下载区

下载页在 `/downloads`，四张卡片排成两行，进哪个取决于你想下什么。

![资源下载页](/screenshots/downloads.png)

## Minecraft Launcher

第三方启动器合集，GitHub 上那些主流的基本都收了。同一个启动器有多个版本时，点进去能看到各个 releases，按自己系统选就行。

启动器用不了或者报奇怪的错，去 `/downloads/launcher/{启动器的key}/issues` 提 issue。key 就是启动器在列表里的标识，从详情页地址栏看最准。

## EndlessPixel Modpack

服主自己维护的优化整合包，主要做客户端性能和体验优化。服务器玩法全靠插件提供，连锁挖掘、领地、粘液科技这些功能在服务端就有，不装整合包也能用。

`/downloads/modpack` 列出各个版本和对应的更新日志。选版本的时候注意看兼容的 Minecraft 版本，本服当前主推 26.3，跨版本兼容靠 ViaVersion，但客户端差太远还是容易出问题。

整合包出问题去 `/downloads/modpack/issues`，把报错原文和复现步骤贴上，别只说一句用不了。

## Modpack APP

一个下载工具，给整合包用的。如果你只是想快速拿到最新整合包，不想手动翻 GitHub releases，用这个会省事一些。

## 自定义下载

这个最灵活。输入任意 GitHub Releases 地址，工具会解析里面的文件生成一个下载页。想下载别的启动器或者模组，又不想记直链，可以走这里。

## 几个实际建议

第一次进服的话，官方整合包加上任意一个顺手的启动器就够了，不用每个下载项都装一遍。

客户端版本别追太新。本服兼容区间是 `1.7.2 ~ 26.3`，用 26.3 最稳妥。预发布版和快照可能有协议差异，玩着玩着掉线很烦。

下载慢可以换网络环境，或者看看 GitHub 那个源能不能直连。整合包体积不小，断网续传比反复重下省事。
