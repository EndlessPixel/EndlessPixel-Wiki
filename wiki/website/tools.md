# 官网在线工具

除了游戏和下载，官网还放了几个网页工具。都不用装东西，浏览器打开就能用。

## 服务状态

`/status` 是最值得收藏的一页。上面几个卡片分别盯着网站、Minecraft 服务器、AI 对话、模型排行和性能监控，当前状态、响应耗时、近 30 天可用率都在上面。

![服务状态监控](/screenshots/status.png)

时间线一天一格，绿色是全天没问题，黄色说明有零星失败，红色是当天大面积异常，灰色表示那天没采到数据。鼠标悬停能看当天每一次检测的时间和结果。

状态数据每 5 分钟自动更新一次，也可以点刷新按钮手动来一次。更底层的历史数据是 GitHub Actions 每小时跑一次探测存下来的，放在独立的公开仓库里。

想知道 MC 服务器具体多少人在线、用的什么版本，去 `/status/mcserverstatus`。

## 服务器考试

`/quiz` 是个答题页面，题库涵盖接入地址、版本体系、玩法规则、整合包和 API 这些。

![服务器考试](/screenshots/quiz.png)

题量自己选，5 到 100 题都行，每道题只有一个正确答案，交卷后会给解析。题库里有一部分题专门考开发者文档，比如 API 路径和语言文件键名。

成绩存在浏览器 localStorage 里，不上传服务器。换设备就没了，介意的话自己截图留着。

## 模型排行

`/rankings` 显示 AI 模型用量榜，按不同的时间窗口看。数据来自同一台上游代理，跟对话接口共用地址。

![模型排行](/screenshots/rankings.png)

这个页面跟游戏玩法没关系，是给官网 chatbot 做的数据展示。

## 玩家截图图册

`/gallery` 收集玩家上传的游戏截图。支持切换加速节点，图源默认是 GitHub RAW。

上传走 Wiki 那边的[图片上传接口](/dev/image_upload)，不是官网这个页面。注意版权声明，图册内容按 CC BY-NC-SA 4.0 来保护。

## 服务器实况

`/live` 放服务器实况录像和精彩回放。想看看别人在服里干嘛，或者自己想找点建筑灵感，可以逛逛。

## 皮肤预览

`/skin` 是个独立的预览工具，输入角色名就能看 3D 皮肤，支持正版和 LittleSkin 两个来源。不用登录。

粗臂细臂根据皮肤纹理自动识别。查不到会直接提示未找到，不会悄悄退回默认皮肤糊弄你。

预览里的角色可以点，点一下会有动作和抖动反馈。连点几次还会触发红闪，这个彩蛋是从美西螈启动器那边学来的。
