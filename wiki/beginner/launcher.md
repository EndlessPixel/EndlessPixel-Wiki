# 启动器推荐

EndlessPixel 只接受 **Java 版**客户端接入。电脑端原版、整合包，以及手机端的 Java 版启动器，接入方式完全一致。

::: info
基岩版（手机/主机/Win10 原版 App、网易版）协议与账号体系不同，**无法连入** 本服。
手机端想玩 Java 版，需要用下方的移动端启动器。
:::

## 桌面端（Windows / macOS / Linux）

### PCL2
- **适用平台**：Windows
- **简介**：Windows 平台主流 Minecraft 第三方启动器，国内用户基数大，配置简单，版本管理与下载流程轻量化。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/pcl-2
- **GitHub**：https://github.com/Meloong-Git/PCL

### PCL2 社区版
- **适用平台**：Windows
- **简介**：PCL2 社区维护衍生版本，持续迭代修复问题，功能逻辑与原版 PCL2 相近。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/pcl2-ce
- **GitHub**：https://github.com/PCL-Community/PCL2-CE

### HMCL（跨平台）
- **适用平台**：Windows、macOS、Linux
- **简介**：支持全平台的老牌第三方启动器，版本管理、模组安装、离线登录等功能完备，兼容性覆盖面广。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/hmcl
- **GitHub**：https://github.com/HMCL-dev/HMCL

### PrismLauncher
- **适用平台**：Windows、macOS、Linux
- **简介**：由 MultiMC 分支发展而来的开源跨平台启动器，实例隔离管理成熟，对整合包、模组批量管理较为友好。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/prismLauncher
- **GitHub**：https://github.com/PrismLauncher/PrismLauncher

## 移动端（手机运行 Java 版）

### PojavLauncher（安卓）
- **简介**：安卓平台运行 Minecraft Java 版通用开源启动器，是手机游玩 Java 版较为普遍的基础方案。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/pojav
- **GitHub**：https://github.com/PojavLauncherTeam/PojavLauncher

### PojavLauncher（iOS）
- **简介**：Pojav 针对 iOS 系统适配的版本，实现在苹果设备运行 Minecraft Java 版。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/pojav-ios
- **GitHub**：https://github.com/PojavLauncherTeam/PojavLauncher_iOS

### FCL 手机启动器（安卓）
- **简介**：国产安卓端 Minecraft Java 版启动器，针对触屏操作做了适配优化，在原生 Pojav 基础上做了本土化修改。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/fcl
- **GitHub**：https://github.com/FCL-Team/FoldCraftLauncher

### HMCL-PE（移动端）
- **简介**：HMCL 针对移动设备开发的版本，用于手机端运行 Minecraft Java 版。
- **本站下载**：https://www.endlesspixel.cn/downloads/launcher/hmcl-pe
- **GitHub**：https://github.com/HMCL-dev/HMCL-PE

## 下载与安装提示

- 整合包为 **Modrinth 打包格式**，推荐使用 Modrinth 官方启动器、PCL2、HMCL 安装部署。
- 本站整合包下载页：https://www.endlesspixel.cn/downloads/modpack
- 服务器**无需正版账号**，原版客户端、离线登录、LittleSkin / HelloSkin 第三方皮肤账号均可直连。
