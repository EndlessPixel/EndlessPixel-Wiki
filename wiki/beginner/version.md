# 服务器版本说明

## 服务器支持版本
服务器支持 `1.7.2` 至 `26.3` 区间的客户端直接登录，从经典旧版本到最新版本都能连接，无需额外调整版本文件。

## 推荐版本
`26.2` 是本服务器的推荐版本，与核心插件、模组和特色功能适配最好，能完整支持所有玩法内容。

## 协议号
服务器协议号为`776`。这个协议号是实现跨版本正常连接的核心参数，服务器已通过插件自动完成协议转换，玩家无需手动修改客户端协议配置，直接使用对应版本客户端即可正常登录。

## 版本兼容性分级

### 最佳体验
使用 `26.2` 版本登录可获得最佳体验，能完整支持所有最新特性，包括新增维度内容、特色附魔系统、领地管理功能等，运行流畅度也最好。

### 🔧 兼容版本
`1.7.2`至`26.3`版本的客户端均可正常进入服务器。对于非推荐版本，服务器会通过`ViaVersion`插件自动适配基础功能，保证玩家能够正常进行生存、建造、战斗等核心玩法。

## 关于 26.x 新版本号体系

自 2026 年起，Mojang 的正式版版本号统一改为以 `26.` 开头，规则是 **`年份.年内更新序号`**，例如 `26.1`、`26.1.2`、`26.2`、`26.3`。

::: info
`1.x` 体系（如 `1.21.11`）是 2024–2025 年的稳定正式版，属于官方正统版本，**并没有作废**，只是新一代版本号改用了年份开头。
:::

- **快照命名格式**：`年份.年内更新序号-snapshot-快照号`，例如 `26.4-snapshot-1`。
- **开发中的版本**：`26.4` 目前仍在开发中（已发布多个 snapshot），**尚未发布正式版**，暂不能用于登录本服。
- **Java 版 / 基岩版**共用年份前缀，但后缀独立编号，不可互相混用；本服仅接受 Java 版客户端。
- 从 `26.1` 起，客户端启动最低要求 **Java 25**。
